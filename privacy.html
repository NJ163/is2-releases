IS² プライバシーポリシー

制定日：2026年9月25日

IS²（アイシス。PDF の閲覧・編集を行う Windows 用アプリ。以下「本アプリ」）の提供者（以下「提供者」）は、本アプリのログインとライセンスの確認で取り扱う利用者の情報について、次のとおり定めます。

1. 提供者

中條寛海

2. 取得する情報

利用者が本アプリで Google アカウントによるログインを行ったとき、利用者の同意のうえで、Google から次の情報を受け取ります。

  • Google アカウントのメールアドレス
  • Google アカウントを識別する番号（Google が発行する利用者ごとの識別子）
  • 所属する組織のドメイン（Google Workspace のアカウントの場合）

あわせて、本アプリは次の情報を扱います。

  • 本アプリのインストールごとに作る識別番号（乱数。パソコンや個人を特定する情報からは作りません）
  • ライセンスの確認のために提供者のサーバへ接続したときの IP アドレス

3. 利用目的

  • 利用者の本人確認
  • ライセンス（契約、席数、同じアカウントの同時利用）の確認
  • 不正利用の防止

これ以外の目的には使いません。広告には使いません。

4. 保存のしかた

  • 利用者のパソコン：メールアドレスと、ログインを続けるための情報を保存します。ログインを続けるための情報は、Windows の機能（DPAPI）で暗号化し、そのパソコンのその利用者でしか読めない形で保存します。ログアウトすると削除します。
  • 提供者のサーバ：Google アカウントの識別番号は、元に戻せない形（ハッシュ）に変えて保存します。メールアドレスは保存しません。IP アドレスは不正利用の調査のために記録し、90日を過ぎたものから消去します。

5. 送らない情報

本アプリで開いた文書（PDF 等）の内容は、ログインやライセンスの確認のために送ることはありません。

ただし、利用者が本アプリの設定で「AI 読取」を自ら有効にした場合に限り、読み取りを指示した文書を、利用者が選んだ AI の提供元（Google、OpenAI、Anthropic、または利用者が指定した送信先）へ送ります。この送信は、利用者が設定した送信先へ直接行われ、提供者のサーバを経由しません。

6. 第三者への提供

法令に基づく場合を除き、取得した情報を第三者に提供しません。ログインには Google のサービスを、ライセンスの確認のサーバには Cloudflare のサービスを利用しています。

7. Google のユーザーデータの取り扱い

本アプリが Google API から受け取った情報の利用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。

8. 開示・訂正・削除のご請求とお問い合わせ

ご自身の情報の開示・訂正・削除のご請求、その他のお問い合わせは、お問い合わせ窓口（GitHub）からお寄せください。

9. 改定

このポリシーを改定するときは、このページでお知らせします。
