IS² プライバシーポリシー

制定日：2026年9月25日

IS²（アイシス。PDF の閲覧・編集を行う Windows 用アプリ。以下「本アプリ」）の提供者（以下「提供者」）は、本アプリのログインとライセンスの確認で取り扱う利用者の情報について、次のとおり定めます。

1. 提供者

中條寛海

2. 取得する情報

利用者が本アプリで Google アカウントによるログインを行ったとき、利用者の同意のうえで、Google から次の情報を受け取ります。

  • Google アカウントのメールアドレス
  • Google アカウントを識別する番号（Google が発行する利用者ごとの識別子）
  • 所属する組織のドメイン（Google Workspace のアカウントの場合）

あわせて、本アプリは次の情報を扱います。

  • 本アプリのインストールごとに作る識別番号（乱数。パソコンや個人を特定する情報からは作りません）
  • ライセンスの確認のために提供者のサーバへ接続したときの IP アドレス
  • ログインを続けるために提供者のサーバが発行するセッションの番号と合言葉（どちらも乱数）

ライセンスの確認では、Google が発行したログインの証明（ID トークン。上の情報を含みます）を提供者のサーバへ送ります。サーバはこれを本人と契約の確認に使うだけで、保存しません。

本アプリの更新を確かめるときは、提供者のサーバが発行したライセンスの証明（インストールごとの識別番号とセッションの番号を含みます）を提供者のサーバへ送ります。サーバはこれを契約の確認に使うだけで、保存しません。

3. 利用目的

  • 利用者の本人確認
  • ライセンス（契約、席数、同じアカウントの同時利用）の確認
  • 不正利用の防止

これ以外の目的には使いません。広告には使いません。

4. 保存のしかた

  • 利用者のパソコン：メールアドレス、Google アカウントの識別番号、ログインを続けるための情報を保存します。ログインを続けるための情報のうち合言葉にあたるものは、Windows の機能（DPAPI）で暗号化し、そのパソコンのその利用者でしか読めない形で保存します。ログアウトするとこれらを削除します（インストールごとの識別番号だけは残します）。
  • 提供者のサーバ：本アプリの契約がある組織のアカウントでログインしたときだけ、次の情報を保存します。
    • Google アカウントの識別番号（元に戻せない形（ハッシュ）に変えて保存します）
    • インストールごとの識別番号、セッションの番号、合言葉（元に戻せない形（ハッシュ）に変えて保存します）、セッションを始めた日時・最後に確認した日時・終えた日時とその理由
    • 席の利用（ハッシュに変えた識別番号ごとに、最初と最後に使った日時・席を空けた日時）
    • 確認の中で起きた出来事の記録（同じアカウントの別の場所での利用、席数の超過、接続元の変化などの種類と日時、ハッシュに変えた識別番号、インストールごとの識別番号）
    • IP アドレス（セッションには最後に接続したときのもの、出来事の記録にはそのときのもの）
    IP アドレスは不正利用の調査のために記録します。保存した情報は、毎日1回の掃除で、次の期間を過ぎたあと1日以内に消去します。
    • セッション：最後に確認してから30日使われなければ終え、終えてから90日で、IP アドレスとあわせて消去します（使っている間は、同じアカウントの同時利用を防ぐために残します）。
    • 席の利用：最後に使ってから30日で席を空け、空けてから90日で消去します。
    • 出来事の記録：利用者（アカウントや端末）に紐づく記録は90日で消去します。IP アドレスは、どの記録からも90日で消去します。利用者に紐づかない管理の記録（全体の設定の変更、件数のまとめなど）は残しますが、個人の情報は含みません。
    • 契約が終わった組織：契約の期限から90日で、その組織のセッション・席の利用・出来事の記録を消去します（契約と組織そのものの記録は残します）。
    メールアドレスは保存しません。契約のない組織のアカウントや個人のアカウントでログインしたときは、契約の有無を確かめるだけで、サーバには何も保存しません（接続の回数が多すぎないかを確かめるための一時的な数え上げは除きます。1分で消えます）。

5. 送らない情報

本アプリで開いた文書（PDF 等）の内容は、ログインやライセンスの確認のために送ることはありません。

ただし、利用者が本アプリの設定で「AI 読取」を自ら有効にした場合に限り、読み取りを指示した文書を、利用者が選んだ AI の提供元（Google、OpenAI、Anthropic、または利用者が指定した送信先）へ送ります。この送信は、利用者が設定した送信先へ直接行われ、提供者のサーバを経由しません。

6. 第三者への提供

法令に基づく場合を除き、取得した情報を第三者に提供しません。ログインには Google のサービスを、ライセンスの確認のサーバには Cloudflare のサービスを利用しています。

7. Google のユーザーデータの取り扱い

本アプリが Google API から受け取った情報の利用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。

8. 開示・訂正・削除のご請求とお問い合わせ

ご自身の情報の開示・訂正・削除のご請求、その他のお問い合わせは、お問い合わせ窓口（GitHub）からお寄せください。

9. 改定

このポリシーを改定するときは、このページでお知らせします。
